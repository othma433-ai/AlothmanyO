# WA Al-Othmany Android v2.1 Actions Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add verified, resumable invite joining and controlled publishing to the existing Android extraction app.

**Architecture:** A dedicated action engine consumes persistent Room queues. `WhatsAppUiBridge` performs bounded stateful UI operations; success is persisted only after state transition verification. The existing extraction engine remains separate.

**Tech Stack:** Kotlin, Android AccessibilityService, Room 2.8.5, coroutines, Foreground Service.

**Spec:** `docs/superpowers/specs/2026-09-15-v2.1-actions-engine-design.md`

## Global Constraints
- minSdk 26, target/compileSdk 35.
- Room stays 2.8.5.
- No unbounded UI waits.
- No private WhatsApp DB access or approval/rate-limit bypass.
- Preserve v2.0 extraction behavior.
